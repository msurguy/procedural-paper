# Changelog

## 0.1.0

Initial public release.

- Seeded, seamless procedural paper textures with WebGL2 and CPU backends.
- Paper sheets and 25 presets, with vanilla JavaScript and React APIs.
- Versioned compositions with editable content, photos, attachments and motion.
- Exporter and Desk demo views, including component source and asset ZIP exports.
- MIT project code, with separate notices for third-party algorithms, fonts and media.
